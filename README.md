# Budget Assist DE

Инфраструктурный шаблон и рабочий прототип системы автоматизации управления персональным бюджетом для людей с инвалидностью в Германии. Проект ориентирован на сотрудничество с социальными ведомствами, социальными организациями, волонтёрскими службами сопровождения и специалистами социальной работы.

## Что внутри

- Документация по продукту, дизайну и технической реализации.
- Минимальный прототип CLI для учёта доходов/расходов и генерации краткого отчёта.
- Базовые инфраструктурные файлы для развёртывания.

## Быстрый старт (CLI прототип)

```bash
python -m budget_app.cli init --storage data/budget.json
python -m budget_app.cli add-income --storage data/budget.json --amount 1200 --source "Sozialhilfe"
python -m budget_app.cli add-expense --storage data/budget.json --amount 45 --category "Mobilität" --note "Taxi"
python -m budget_app.cli summary --storage data/budget.json
```

Этот репозиторий является стартовым шаблоном. Для промышленного использования потребуется адаптация под требования конкретного ведомства и регулятора (GDPR/BDSG), а также проведение аудита безопасности и доступности.
